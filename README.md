## Why "🏝️"?

A desert island is the dream vacation in a single picture — no meetings, no notifications, just sand, sea and nowhere to be. It needs no caption: every reader pictures the same escape, which is exactly what one emoji is for.

## How it works

`main.ts` (Node 22, stdlib only, no network) writes exactly one emoji — `🏝️`, no trailing newline — to `/output/entry.txt`, after a guard that the entry is non-empty, has no whitespace, and is at most 4 Unicode code points.

## Run it

```sh
node main.ts
```

Then check the entry:

```sh
cat /output/entry.txt   # 🏝️
```
